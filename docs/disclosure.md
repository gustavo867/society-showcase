# Disclosure scope

This is a documentation-only case study using an editorial project name. The original brand is deliberately withheld. The source application is private, and this package includes no application implementation or operational dataset.

Images were authorized by the owner with the requirement to withhold the original name. Captures use an isolated web-preview copy, fictitious teams and sanitized configuration. The diagram describes component responsibilities without infrastructure identifiers. The animated media is a loop of captured screens rather than a native recording. [Media provenance](../assets/README.md)

Publication of this documentation-only showcase and its sanitized images was explicitly authorized by the owner. Personal attribution remains limited to the evidence below. Screenshot authorization does not establish independent ownership of embedded third-party illustrations; no separate illustration asset or third-party license is redistributed here. No source-application license is copied into this showcase.

Private analysis, original fixtures, source maps, bundles, logs, credentials, account/project identifiers and store/build dashboards are outside this public directory. Personal-role claims, adoption, performance gains and store availability are limited to verified evidence; unresolved claims are labeled accordingly. [Evidence register](evidence.md)

# Media provenance

- `architecture.png`: original conceptual diagram created for this case study from the observed component/data-flow boundaries. It contains no code, private URLs, account identifiers or original branding.
- `screenshots/agenda.png`: real sanitized web-preview capture with fictitious teams Alpha and Beta.
- `screenshots/create.png`: real sanitized web-preview capture of the booking form with fictitious team Gamma. The form was filled for illustration; submitting a booking was not part of this capture.
- `screenshots/backup.png`: real sanitized web-preview capture. Its displayed count refers only to synthetic records; bundled original backups were replaced with empty data in the preview copy.
- `demo.gif`: animated screen walkthrough assembled from the three PNG captures, with pauses between screens. It is not a continuous interaction recording.

All UI captures were taken on 7 November 2026 at the iPhone 12 Pro portrait CSS viewport, **390 × 844**, configured before page loading. They show the web build, not an iOS/Android device or certified native release. The initial tab load also reported two web warnings; navigation to the form reported a React runtime error described in [testing and delivery](../docs/testing-and-delivery.md).

The isolated preview removed the original brand and infrastructure configuration, used dedicated local-storage keys, and replaced private-looking backup content with synthetic/empty data. The original source was not edited for these captures. Screenshot publication was authorized by the owner; this case study makes no claim of independent ownership or a separate reuse license for the embedded illustration.
